Sobre o jogo

Corra, colete XP e vire uma tempestade de projéteis.

SWARM mistura a leitura de espaço de Space Invaders com a progressão de um survivor-like. Cada run é curta, legível e feita para “só mais uma”.

01 · RITMO

10 minutos por run

Runs curtas, decisões rápidas e um boss no meio do caminho. Perfeito para uma pausa.

02 · BUILD

3 upgrades por nível

20 upgrades com pré-requisitos, efeitos duplos e limites. Cada escolha muda o caos.

03 · CLÍMAX

O Núcleo às 5:00

O boss limpa a horda e transforma a run em um duelo. Sobreviva até 10:00 para vencer.

Como participar

Você recebeu um convite? Siga estes passos.

O playtest é fechado: o link e a senha do itch.io vão na mensagem do convite.

  1. Abra o convite

    Use o link com senha enviado no Discord, WhatsApp ou e-mail.

  2. Baixe e extraia

    Baixe o ZIP e extraia a pasta inteira. Não abra o executável de dentro do ZIP.

  3. Jogue uma run

    Vá até o boss (5:00) ou até morrer. Se morrer antes de 3 min, tente mais uma.

  4. Envie o feedback

    Volte aqui e responda o formulário de 3 minutos. É anônimo.

Windows SmartScreen: o executável não é assinado. Se aparecer “aplicativo não reconhecido”, clique em Mais informações → Executar assim mesmo. Se o jogo abrir mudo, aperte O e depois +.
