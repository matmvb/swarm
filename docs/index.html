Como testar

  1. Baixe o ZIP no link do convite e extraia em uma pasta.
  2. Execute SWARM.exe. Se o Windows avisar que o app não é reconhecido, clique em Mais informações → Executar assim mesmo.
  3. Jogue uma run até o boss (5:00) ou até morrer.
  4. Volte aqui e clique em Enviar feedback.

Se o jogo abrir mudo, aperte O e depois + para aumentar o volume.

O que estou testando
